# Demo video

The demo package lives in [`demo/`](../demo/):

* [`demo/SCRIPT.md`](../demo/SCRIPT.md) — the narration, timestamped
* [`demo/STORYBOARD.md`](../demo/STORYBOARD.md) — scene table: visuals, actions, narration
* [`demo/CHECKLIST.md`](../demo/CHECKLIST.md) — setup, recording, editing, quality control
* `demo/assets/` — title, section and end cards, and lower-third overlays
* `demo/reference/` — a 3:51 reference cut recorded from the real console
  (rebuild with `python scripts/demo_record.py --assemble`)
